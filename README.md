# האתר של איילה – החלקות אורגניות ושיקום שיער

אתר פשוט ב-HTML ו-CSS, בלי שרת.

## הקבצים
- `index.html` – דף הבית
- `services.html` – ההחלקות והמחירים
- `products.html` – המוצרים והמחירים
- `contact.html` – כתובת, טלפון, וויז
- `styles.css` – כל העיצוב. הצבעים מוגדרים בראש הקובץ
- `assets/` – הלוגו, הסרטון ותמונות המוצרים

## איך משנים מחיר או טקסט
פותחים את קובץ ה-HTML של הדף, מחפשים את הטקסט (Ctrl+F), משנים ושומרים.
אחרי העלאה ל-GitHub, האתר מתעדכן לבד תוך דקה-שתיים.

## קביעת תור
כרגע דרך וואטסאפ. מערכת תורים עם שרת תבוא בהמשך.
